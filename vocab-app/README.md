# Phrase Master 400

英語フレーズ400語を、4択テストと復習で身につけるためのスマホ向けPWAです。
ビルド不要の静的サイト（HTML/CSS/JavaScript）で、進捗は端末のブラウザ内に保存されます。

## 使い方

1. 静的ホスティング（GitHub Pages など）で `vocab-app/` を公開するか、ローカルで起動します。
   ```sh
   cd vocab-app
   python3 -m http.server 8000   # → http://localhost:8000
   ```
2. スマホで開き、「ホーム画面に追加」するとアプリのように使えます（オフラインでも学習可能）。

## 出題形式

- フレーズ（例: `cut corners`）を見て、その意味に合う **英語の言い換え** を4択から選びます。
  誤答の3つは他のフレーズの言い換えから、同じ品詞のものを優先して選びます（意味が重なる類義グループは除外）。
- 解答後は、正解の言い換え・和訳・例文（英文と和訳）を表示します。🔊で読み上げもできます。

## 進め方

- **新しい語**: No.001 から順に20語ずつ一気に出題。間違えた問題だけをもう一度出題し、全問正解するまで繰り返したら次の20語に進めます。
- **復習**: 翌日以降、期限が来た語を20語ずつ同じ方式で出題します。
- **マスター**: セッションで最初の解答が正解だった場合を「一発正解」とし（1日1回まで）、通算3回でマスター。
  一発正解のあとは 1日後 → 3日後 …、間違えた語は翌日に復習に出ます。
- 途中でやめても、ホームの「続きから再開」で再開できます。
- 必要回数（1〜5回）と1回の語数（10/20/30）は設定で変更できます。

## ファイル構成

```
vocab-app/
├── index.html
├── manifest.webmanifest / sw.js   PWA設定・オフラインキャッシュ
├── css/style.css
├── icons/
└── js/
    ├── words1.js〜words4.js  フレーズデータ（各100語）
    ├── data.js     データの読み込み
    ├── store.js    進捗・設定の保存
    ├── engine.js   出題・判定・復習スケジュール
    └── app.js      画面
```

## データ形式

`js/words*.js` の各行は次の形式です（番号は並び順で決まります）。

```js
['cut corners', 'v', 'do sth the quickest or cheapest way, sacrificing quality',
 '手抜きをする', "We can't cut corners on security.", 'セキュリティで手抜きはできない。'],
// [見出し語, 品詞(v/a/n/x), 英語の言い換え, 和訳, 例文, 例文和訳, 類義グループ(任意)]
```
