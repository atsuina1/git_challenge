# C1 Vocab Master

C1レベルの日常会話・ビジネス英語（特にIT系）の単語／熟語／フレーズを習得するための、スマホ向けPWAです。
ビルド不要の静的サイト（HTML/CSS/JavaScript）で、進捗は端末のブラウザ内に保存されます。

## 使い方

1. 静的ホスティング（GitHub Pages など）で `vocab-app/` を公開するか、ローカルで起動します。
   ```sh
   cd vocab-app
   python3 -m http.server 8000   # → http://localhost:8000
   ```
2. スマホで開き、「ホーム画面に追加」するとアプリのように使えます（オフラインでも学習可能。AI機能はオンライン時のみ）。

## 出題形式

各単語は次の4形式を順番に学習します。前の形式で1回正解すると、次の形式が解放されます。

| 形式 | 内容 |
|---|---|
| 英→和 | 見出し語の意味を4択で選ぶ |
| 例文→和訳 | 例文中のマーカー部分の訳を4択で選ぶ |
| 和→英 | 日本語から英語を答える（レベルに応じて 選択式／頭文字ヒント付き入力／自由入力） |
| 例文作成 | その表現を使った英文を自分で書く（AI採点、またはAIなしなら模範例と比べて自己採点） |

## パスのルール

- 形式ごとに **3回正解でパス**（設定で1〜5回に変更可）。4形式すべてパスで「マスター」。
- 1回目の正解後は同じセッション内でもう一度出題し、その後は 1日 → 3日 → … と間隔を空けて出題します。
- 不正解の場合は正解カウントを1減らし（設定で0に戻すことも可）、セッション内で再出題します。

## レベル調整

**自動調整（AIなし）**: 直近の正答率から次の項目を調整します。
- 1回あたりの新出単語数（正答率が高いと増やし、低い・復習が溜まっていると減らす）
- 新出単語の難易度上限（Lv.1〜3）
- 選択肢の紛らわしさ（得意な形式では同じカテゴリ・同じ種類から誤答選択肢を出す）
- 和→英の出題形式（選択式 → ヒント付き入力 → 自由入力）
- 正答率の低いカテゴリを重点的に復習

**AIコーチ（任意）**: 設定画面で Anthropic の APIキーを入力すると、ホーム画面の「AIコーチ」で次のことができます。
- 学習データの分析コメント
- 上記パラメータの調整（7日間有効、設定画面から解除可）
- 弱点やレベルに合わせた新しい単語の追加
- 例文作成問題の自動採点・添削

APIキーは端末のブラウザ内（localStorage）にのみ保存され、ブラウザから Anthropic API へ直接送信されます。
エクスポートしたファイルには含まれません。API利用料は従量課金です。

## ファイル構成

```
vocab-app/
├── index.html
├── manifest.webmanifest / sw.js   PWA設定・オフラインキャッシュ
├── css/style.css
├── icons/
└── js/
    ├── data.js     初期単語データ（55語）
    ├── store.js    進捗・設定の保存
    ├── engine.js   出題スケジュール・判定・自動レベル調整
    ├── ai.js       Claude API 連携
    └── app.js      画面
```

## 単語の追加

`js/data.js` の `WORDS` に次の形式で追加します（`m` は `ex` 中の、`hl` は `exJa` 中の完全一致部分文字列）。

```js
{ id: 'mitigate', t: 'mitigate', k: 'word', c: 'it', lv: 2, ja: '（影響・リスクを）軽減する',
  ex: 'We rolled back the deployment to mitigate the impact on users.', m: 'mitigate',
  exJa: 'ユーザーへの影響を軽減するためにデプロイをロールバックした。', hl: '軽減する' },
```

`k`: `word` / `idiom` / `phrase`、`c`: `daily` / `biz` / `it`、`alt`: 和→英で正解とする別表記（任意）。
